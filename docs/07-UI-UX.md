# UI/UX

## Overview

Spesifikasi antarmuka dan pengalaman pengguna Jarvis yang berfokus pada kesederhanaan layout, kecepatan akses, dan kenyamanan membaca dokumen atau kode pemrograman[cite: 4].

## Goals

- Menyediakan layout workspace dua kolom yang bersih dan modern mirip dengan ChatGPT atau Claude Desktop[cite: 4, 8, 10].
- Memastikan pengalaman membaca tulisan hasil AI terasa interaktif dan tidak kaku[cite: 4].
- Memberikan feedback visual yang jelas saat sistem sedang melakukan proses berpikir atau mengeksekusi perintah[cite: 4, 7].

## Specifications

Fitur antarmuka pada Versi 0.1:

- **Chat UI & Sidebar:** Area obrolan utama dan menu riwayat chat[cite: 4, 9].
- **New Chat & Theme:** Tombol pembuat sesi baru dan opsi penggantian tema (dark/light)[cite: 4, 9].
- **Markdown & Code Highlight:** Rendering teks dokumen yang rapi dan pewarnaan sintaksis kode pemrograman[cite: 4, 9].
- **UX Helpers:** Tombol Copy Message, fitur Auto Scroll ke bawah, dan Typing Indicator (animasi mengetik)[cite: 4, 9].

## Notes

Desain UI dirancang responsif menggunakan Tailwind CSS agar komponen-komponennya terpisah secara modular dan mudah dikembangkan di kemudian hari[cite: 8].
