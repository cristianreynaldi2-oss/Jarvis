# Features

## Overview

Matriks pelacakan fitur dan kapabilitas fungsi Project Jarvis yang dipetakan berdasarkan urutan rilis versi sistem (versioning)[cite: 2].

## Goals

Memastikan setiap fitur dikembangkan secara bertahap dan teratur sesuai dengan prioritas urgensinya[cite: 2, 9].

## Specifications

Daftar Matriks Fitur:

- **v0.1 (Frontend Pondasi):** Chat UI, Sidebar, New Chat, Theme, Session Memory, Markdown, Code Highlight, Copy, Auto Scroll, Typing Indicator[cite: 2, 9].
- **v0.2 (Backend Core):** Express.js Server & REST API[cite: 2, 3, 9].
- **v0.3 (Database Layer):** SQLite Integration & Prisma ORM[cite: 2, 8, 9].
- **v0.4 (AI Integration):** Local AI Connection via Ollama[cite: 2, 9].
- **v0.5 (OS Extension):** Tools Manipulation (File, Folder, Terminal)[cite: 2, 7, 9].
- **v0.6 hingga v0.9 (Smart Tools):** Web Search, PDF Reader, Speech to Text, dan Plugin Ecosystem[cite: 2, 9].
- **v1.0 (Desktop Release):** Electron Packaging (`Jarvis.exe`)[cite: 2, 8, 9].

## Notes

Status pengerjaan dari setiap baris matriks fitur ini akan diperbarui dari _Rencana_ menjadi _Selesai_ pada berkas log rilis utama[cite: 1, 2].
