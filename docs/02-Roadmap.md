# Roadmap

## Overview

Rencana pengembangan Project Jarvis yang dibagi menjadi beberapa fase rilis bertahap untuk memastikan fondasi sistem dibangun secara modular, kokoh, dan stabil sebelum melangkah ke fitur yang lebih kompleks[cite: 9].

## Goals

- **Fase 1: Foundation (v0.1):** Pembuatan Chat UI, Sidebar, New Chat, manajemen tema, serta fitur rendering Markdown dan Code Highlight[cite: 9].
- **Fase 2: Integration (v0.2 - v0.4):** Pembangunan server backend Express.js, integrasi database SQLite + Prisma ORM, dan koneksi ke AI Lokal via Ollama[cite: 9].
- **Fase 3: Capability (v0.5 - v0.9):** Implementasi Tools (File, Folder, Terminal), fitur Web Search, PDF Reader, Speech to Text, dan ekosistem Plugin[cite: 9].
- **Fase 4: Desktop Stable (v1.0):** Pengemasan sistem menggunakan Electron menjadi aplikasi desktop native (`Jarvis.exe`)[cite: 9].

## Target User

Fase-fase ini dirancang dan dijadwalkan sepenuhnya untuk kebutuhan pengembangan mandiri secara bertahap[cite: 9, 10].

## Notes

**Project Rules (Prinsip Pengembangan):**

1. **Offline First:** Memprioritaskan pemrosesan di lokal mesin tanpa ketergantungan internet[cite: 7].
2. **Documentation First:** Setiap langkah arsitektur dan perubahan arah harus tercatat rapi di berkas `.md`[cite: 1].
3. **Keep It Simple:** Fokus pada fungsionalitas pengguna tunggal tanpa overhead fitur kompleks[cite: 7, 10].
