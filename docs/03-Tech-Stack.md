# Tech Stack

## Overview

Pemilihan teknologi dasar pembentuk Project Jarvis yang mengutamakan ekosistem JavaScript (end-to-end), performa komputasi lokal yang ringan, gratis, serta kemudahan dalam proses pengembangan[cite: 7, 8].

## Goals

- **Frontend:** Menggunakan **React** karena sifatnya yang modular dan komponennya terpisah, serta **Tailwind CSS** untuk pembuatan UI modern mirip ChatGPT secara cepat[cite: 8].
- **Backend:** Menggunakan **Node.js** dan **Express.js** agar tetap berbasis JavaScript, mudah dipelajari, serta memiliki dukungan library AI yang banyak[cite: 8].
- **Database:** Menggunakan **SQLite** karena sangat ringan, tidak butuh server database terpisah, dan berbentuk satu file tunggal yang mudah dipindahkan[cite: 8].
- **ORM & AI Runtime:** Menggunakan **Prisma ORM** untuk mempermudah interaksi database[cite: 8], serta **Ollama** sebagai runtime model AI lokal (seperti Qwen)[cite: 5, 9].
- **Desktop Wrapper:** Menggunakan **Electron** untuk membungkus aplikasi web localhost menjadi aplikasi desktop desktop (`Jarvis.exe`)[cite: 8, 9].

## Target User

Teknologi yang dipilih dikhususkan untuk lingkungan lokal (localhost) agar ringan dijalankan di laptop atau PC pribadi pengembang[cite: 7, 8].

## Notes

Seluruh stack yang dipilih bersifat gratis dan open-source, sejalan dengan prinsip pengembangan proyek yang ekonomis dan mandiri[cite: 7].
